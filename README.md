hey, I'm arkivx0. I mostly build small Windows and Android tools for myself and share the ones that turn out useful.

**stuff I've made**
- [BluntyBuds](https://github.com/arkivx0/BluntyBuds) - free offline controller for TOZO earbuds (ANC, EQ, AutoEQ, battery, touch controls). Windows + Android, no account, no tracking.
- [Radio Arkiv](https://github.com/arkivx0/RadioArkiv) - my fork of RadioDroid for Android internet radio, now at 1.0.4. Rewind live radio and jump back to live (with a lock screen seek bar), silent scheduled recordings, a call-crash fix, and 11 themes (Omarchy, Terminal, Enclave, Vintage and more).
- [Northglass](https://arkivx.itch.io/northglass) - a calm weather desk for Windows 10/11 with forecasts, NWS alerts, live radar, and live satellite or radar wallpapers. $1, no ads.
